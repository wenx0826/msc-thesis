This thesis is initiated by the pain that the current state-of-the-art tools mostly only offered a input box, making it inconvenient for source like documents. To address this problem, we proposed and developed an integrated web-based system that supports document-driven process modeling with LLMs through a more seamless, efficient, and user-friendly workflow. 

Here we first summarize the research questions:

RQ1 How do existing tools supported AI-assi§sted process modeling with documents?

A thorough systematic review of the existing tools and approaches for AI-assisted process modeling is conducted, which provides insights into the current state of the art and guides the design of the proposed system. The review shows that most of the existing tools still focus on model generation capabilities and quality. There is an trend to augment the input model to such as audio. However, the use scenario of creating process models from documents or segment of documents only is still missing, which motivates our work.

RQ2: What functionalities should a system provide to support AI-assisted process modeling from documents, and how should these functionalities be designed and integrated in a seamless and user-friendly manner?
Based on the review and communication with modeling experts, we first elicited the minimum requirement for the system, which includes: 1. unified workspace management for correlated documents and models; 2. direct text selection from uploaded documents as LLM input; 3. side-by-side visualization to establish explicit visual links between source text and generated process models; 4. subprocess relationship establishment;
Beyond this, the enhanced requirements include was designed to increase the system's usability: 1. LLM-based model redsign 2. model version control; 3. document version update. 4 document or model bulk management. 5. interactive visualiztion of the document and model relationship through network style graph. During the design, it is felt that the more functionality we want to offer, the more challenge it bring to the system design, and may could  descrease the usability.


RQ3 How do user perceive the benefits and limitation of the system?

The first evalution is conducted with 4 modeling expert. Through the evaluation, we could conclude that in general it is an intuive and usable tool and it shows potential to be particularly valuable for creating and exploring multiple models from documents, especially through features such as text–model links and process–subprocess model links. However, for simpler tasks, such as building a model from a single document, the system offers limited advantages compared to existing tools. Although the version control feature is perceived as useful, it is an appliable feature to other tools as well. Furthermore, two valuable directions for future work were identified from the evaluation: fine-grained traceability between text and model for AI-assisted process modeling, and  AI-assisted document intelligence. Both are considered can support enhancing the system’s efficiency and overall perceived usefulness significantly.
