\section{LLM-based Process Modeling Tool}
\subsection{ProMoAI}
ProMoAI \cite{ProMoAI} is a tool that leverages generative AI to support process modeling. It allows users to create process models by providing natural language descriptions of the processes. The tool uses a large language model (LLM) to generate process models based on the provided descriptions. ProMoAI aims to make process modeling more accessible and efficient by allowing users to create models using natural language, without requiring expertise in process modeling languages or tools.

\subsection{AutoBPMN.AI}
AutoBPMN.AI \cite{AutoBPMN.AI} is a tool that enables conversational process modeling and automation. It allows users to create and redesign process models through iterative conversations with a large language model (LLM) such as Gemini or GPT. The tool supports both text-based input and existing models, generating new or redesigned process models in executable format. AutoBPMN.AI also features automatic layout capabilities for BPMN-like visualizations. The tool has been demonstrated in various scenarios, including the creation and redesign of process models, as well as subsequent process model execution.

\section{Document-based Interaction Tool}
\subsection{NotebookLM?}
NotebookLM \cite{NotebookLM} is a tool that allows users to upload and interact with their documents using a large language model (LLM). It provides a conversational interface for users to ask questions and receive answers based on the content of their documents. NotebookLM is designed to help users quickly find information and gain insights from their documents, making it easier to manage and utilize large amounts of information.
