
In recent years, AI-assisted tools, especially those based on large language models, have developed very rapidly and have been proven to be a promising solution for supporting process modeling tasks.

However, current tools still have several important limitations.  

First, they mainly rely on manual text input, which means users need to explicitly type or copy process descriptions into the system.  

Second, they typically follow a “one model, one view” paradigm, where users can only work on a single model within one session or interface.  

At the same time, in real-world scenarios, process knowledge is usually not created in such structured input formats. Instead, it already exists in various types of documents, such as text files, Word documents, or PDFs.
