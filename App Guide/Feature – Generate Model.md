
  

## Overview



The Generate Model feature allows users to automatically create a process model from selected text passages in a document. The system analyzes the selected content and generates corresponding model elements that can be visualized in the modeling workspace. Users can select one or multiple text segments before triggering the model generation.

---

### Preconditions

- A document is opened in the document viewer.
    

  

### Steps

1. Select a text passage that describes a process or activity.
    
2. Optionally select additional passages from the document.
    
3. Adjust the selection if needed by dragging the selection handles.
    
4. Click the Generate Model button in the modeling toolbar.
    

  

### Result

  

The system analyzes the selected text and generates a process model.

The generated model appears in the modeling workspace editor, where users can review and further refine the model.

  

## Tips and Hints

- You can select multiple text passages before generating the model.
    
- To refine a selection, drag the small selection handles at the beginning or end of the highlighted text.
    
- Selecting text that clearly describes activities or steps typically produces better model generation results.
    
- If the generated model is incomplete, you can manually adjust or extend the model in the workspace.
    

  

## Notes

The generated process model serves as an initial representation of the described process. Users can further refine the model by editing or adding additional elements.
