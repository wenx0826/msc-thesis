Project, Document, Model and Document Model Link are the minimal tables needed to support the proposed system. It is also how the work implemented at the very beginning. Theoretically, the Document Model Link table can be stored as an attribute within the model version, as the system is currently designed to allowing one model can only be derived from one document. But it a decision make very early to store as a separate table to make the possibility to extend a M2M relation easily. 

Model Version and Document Version are the two tables added together after the decision that the system is designed to implement model version control for model modification. Document Version table are added at the time, before the feature is realized, since they are following the similar logic in DB operation level. 

Subprocess Link table is one additional table that is used to support the Project Graph. As this relationship information has been embeded in Model Data, the model visualization itself does not need this data. But for the project graph, the relationship is hard to parse from the data of the model, therefore, a such is designed to retrieve the process-subprocess relationship easily.

Selection and Selection History table are then added when designing the Document Update feature. Before the selections data of one Document Model Link is stored as an attribute in the format of JSON object string. To easier and better support selection auto-reanchor when document upload, selection and selection history are designed as separate tables. As the separate Selection table can make the selection information easier to be retrieved to operate the reanchor. Besides a Selection History is desgined to make it easier to track the quality of reanchor. 

Finally, the Generation Attempt and Version Event table are the two tables designed to monitor the system behavior. The Generation Attempt table is mainly used for monitoring the AI generation and decision result performed by the user. The Version Event is mainly to store the manual edit behaviur or a system auto-update behavior e.g selection reanchor when document upload.
