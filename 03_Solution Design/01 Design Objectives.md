This chapter presents the design of a system that supports document-based process modeling by integrating document interaction and process model construction within a unified environment. Existing approaches often separate document analysis from modeling activities, requiring users to switch between different tools and manually translate textual information into structured models.

To address these challenges, the proposed system is designed with the following objectives.

> **First, to support an integrated modeling environment.**

> The system aims to combine document viewing, text selection, and process model construction within a single interface, enabling users to perform all core activities without leaving the system. This integration is intended to provide a continuous interaction flow and reduce fragmentation between tasks.

> **Second, to enable direct transformation from text to process models.**

> The system is designed to allow users to derive process model elements directly from selected text segments, reducing the need for manual interpretation and re-entry of information. This supports a more streamlined modeling process from unstructured content.

> **Third, to maintain traceability between source text and model elements.**

> The design ensures that links between selected text and generated model components are preserved, allowing users to trace modeling decisions back to their original context and to iteratively refine models based on the source documents.

> **Fourth, to support iterative and extensible modeling.**

> The system allows users to refine, regenerate, and extend process models over time, including the creation of hierarchical relationships such as subprocess structures. This supports evolving modeling tasks and complex process representations.

> Based on these objectives, the system is structured to support an end-to-end workflow that connects document interaction with process modeling in a unified and continuous manner.
