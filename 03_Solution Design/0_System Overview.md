The system is designed as an integrated environment that supports document-based process modeling within a single interface. It combines document interaction and process model construction in a unified workspace.

Users can view documents, select relevant text, and generate process models directly from textual content. The system also supports reviewing and refining generated models, as well as maintaining connections between source text and model elements.

In addition, the system enables users to organise and manage documents and models, and to co
nstruct hierarchical relationships such as subprocess structures.

Overall, the system provides a continuous workflow that connects document content with structured process modeling.

====

The proposed system is an integrated environment that supports document-based process modeling within a unified workspace. It enables users to interact with documents, select relevant text, and generate process models directly from textual content.

The system supports an end-to-end modeling workflow, in which users can move from document interpretation to process model construction and refinement within a single environment. In addition, the system maintains explicit connections between source text and model elements, supporting traceability throughout the modeling process.

Overall, the system aims to provide a coherent modeling experience that integrates document interaction and process modeling, while supporting iterative development and user control.

===


The design of the system is guided by the need to support integrated document-based process modelling. In particular, the system aims to reduce fragmentation between document interaction and modelling activities, maintain traceability between textual content and process models, and support iterative model development, while ensuring usability through a coherent and intuitive workflow.
