====

The proposed system is an integrated environment that supports document-based process modelling within a unified workspace. It enables users to interact with documents, select relevant text, and generate process models directly from textual content.

The system supports an end-to-end modelling workflow, in which users can move from document interpretation to process model construction and refinement within a single environment. In addition, the system maintains explicit connections between source text and model elements, supporting traceability throughout the modelling process.

Overall, the system aims to provide a coherent modelling experience that integrates document interaction and process modelling, while supporting iterative development and user control.
