 ### **Model Change Events — Description**
> This table records **meaningful changes to a model’s semantic state**.
> It is intentionally limited to changes that **affect the model’s content, structure, or analytical properties**, such as initial generation, regeneration, prompt-driven updates, or traceability changes.
> Presentation-level updates (for example, renaming a model) and lifecycle actions that do not alter the model’s analytical state are deliberately excluded.
> Each record represents a **single, completed model change event** and may include contextual metadata only when it is relevant and meaningful for analysis or statistics.
